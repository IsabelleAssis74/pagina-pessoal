# Página Pessoal

Página de apresentação pessoal criada com HTML e CSS, com seção sobre mim, habilidades e contato.

🔗 **Veja funcionando**: https://IsabelleAssis74.github.io/pagina-pessoal

## Tecnologias
- HTML
- CSS

## Funcionalidades
- Apresentação pessoal
- Lista de habilidades
- Links de contato (e-mail, GitHub e LinkedIn)
- Layout que se adapta ao celular

## Como rodar
1. Baixe ou clone o repositório
2. Abra o arquivo `index.html` no navegador

## O que aprendi
- Estruturar uma página com HTML
- Estilizar com CSS (cores, espaçamento, sombras)
- Publicar um projeto no GitHub Pages
